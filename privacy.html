Privacy Policy

Last updated: 2026-11-11

Clipper is a personal tool used only by its owner. This page explains what data it touches.

What data is used

  • The access tokens that YouTube, Instagram and TikTok give after the owner logs in on their official pages.
  • Basic account information needed to upload (for example the channel or account id and name).
  • The video files and captions the owner chooses to upload.

Where the data stays

  • Everything is stored only on the owner's own computer, in a private folder.
  • Nothing is sent to any server of ours. There is no server, no database and no analytics.
  • Data goes only to the platform the owner is posting to (YouTube, Instagram or TikTok), through its official API.
  • Nothing is sold or shared with anyone else.
  • For Instagram, the video file is placed for a few minutes on the owner's own file storage so Instagram can fetch it, then deleted.

Passwords

The tool never sees a password. Login happens on the platform's own page.

Removing access and data

The owner can remove the tool's access at any time in the security settings of YouTube/Google, Instagram or TikTok, and can delete the saved tokens by deleting the private folder on his computer.

This website

This website is static. It has no cookies, no tracking and no forms.
